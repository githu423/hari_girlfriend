# Taruh file kamu di sini

1. `video.mp4`            -> video kejutan (muncul setelah hati penuh 100%)
2. `signature.png`        -> PNG tanda tangan Ibah Misbah (background transparan, tinggi ~300px)
3. `song.mp3`  (opsional) -> musik latar, diputar lewat tombol 🎵 pojok kanan atas
4. `video-poster.jpg` (opsional) -> thumbnail video

Kalau `signature.png` belum ada, otomatis diganti tulisan tangan "Ibah Misbah".
Ganti tanggal jadian di `script.js` bagian `CONFIG.jadian`.
