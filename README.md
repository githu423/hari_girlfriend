# 🌹 Happy My Girl Day — Sinta Liya

Hadiah web dari **Ibah Misbah** untuk **Sinta Liya**. Static murni (HTML+CSS+JS), tanpa build, super ringan.

## Isi
- Gerbang pembuka + animasi kelopak mawar jatuh & hati terbang
- Ucapan beranimasi mesin ketik + surat cinta
- Boneka pinguin lucu (ala Bad Badtz-Maru) yang bisa dicolek & ngomong
- Buket 7 mawar merah, tiap mawar ada pesan rahasia
- Interaksi "isi hati sampai 100%" sebelum video terbuka
- Sertifikat My Girl Day + tanda tangan Ibah (PNG) & area coretan tanda tangan Sinta, bisa di-download PNG

## Cara pakai
Masukkan file manual ke folder `assets/`: `video.mp4`, `signature.png`, (opsional `video-poster.jpg`).

## Deploy ke Vercel
```bash
npm i -g vercel && vercel
```
Atau import repo ini di vercel.com — Framework Preset: **Other**, build command kosong, output directory: `./`
